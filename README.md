# 🩺 ระบบประเมินการไปพบแพทย์ของผู้สูงอายุ
**Elderly Medical Decision Support System**

โปรเจกต์ปี 4 (Senior Project) - ระบบช่วยตัดสินใจสำหรับผู้สูงอายุและผู้ดูแล ในการประเมินว่าควรไปพบแพทย์หรือไม่

## 🌟 คุณสมบัติ
- ✅ ประเมินอาการจากแบบสอบถาม 20+ อาการ
- ✅ วิเคราะห์ความเสี่ยง 3 ระดับ (สูง/กลาง/ต่ำ)
- ✅ คำนวณคะแนนถ่วงน้ำหนักตามโรคประจำตัวและอายุ
- ✅ แนะนำการปฏิบัติตัวที่เหมาะสม
- ✅ บันทึกประวัติการประเมิน
- ✅ UI สวยงาม ใช้งานง่าย เหมาะกับผู้สูงอายุ
